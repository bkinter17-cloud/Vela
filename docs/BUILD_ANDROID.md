# بناء Iraq Maps عبر GitHub Actions

> **الحالة:** لم يُبنَ المشروع بعد. الكود المعدّل لم يُترجم ولم تُشغَّل اختباراته (بيئة التطوير التي عُدّل فيها لا تصل إلى Maven/Google). أول تشغيل لسير العمل هو أول اختبار فعلي، وقد يكشف أخطاء ترجمة تُصلَح بعده.

## الخطوات

1. أنشئ **Fork** (أو مستودعاً جديداً) على حسابك وادفع إليه الفرع `feature/iraq-maps`.
2. في المستودع: **Settings → Actions → General** وفعّل Actions.
3. **Actions → Iraq Maps - Build → Run workflow** (أو ادفع أي تغيير غير توثيقي إلى الفرع).
4. بعد انتهاء التشغيل، من صفحته: **Artifacts → `iraq-maps-debug-apk`** ثم فك الضغط للحصول على `.apk`.
5. على الهاتف: فعّل "التثبيت من مصادر غير معروفة" للتطبيق المستخدم في التثبيت وثبّت الملف.

## ملاحظات

- لا يحتاج سير العمل أي أسرار (Secrets). الـ APK الناتج **debug** موقّع بمفتاح debug، للتجربة فقط.
- **Forks:** GitHub يعطّل سير العمل المجدولة في الـ Forks افتراضياً. اتركها معطّلة؛ ورثنا من Vela عشرات سير العمل لخطوط بياناته (cron) ولا تخص Iraq Maps.
- **الملفات الثنائية الخارجية:** يجلب البناء ستة ملفات (OsmAnd jars، Cronet AAR، TTS AAR) من إصدارات مستودع Vela الأصلي إذا لم تكن في مستودعك. للتخلص من هذا الاعتماد، أنشئ في مستودعك إصدارات بنفس الوسوم (`obf-runtime`، `cronet-runtime`، `tts-runtime`) وارفع الملفات نفسها؛ الخطوات تجرّب مستودعك أولاً. (تحققت بتاريخ 2026-10-19 أن الملفات متاحة وبأحجامها المتوقعة.)
- **توقيع الإصدار:** لإصدار رسمي أنشئ مفتاح توقيع **خاصاً بـ Iraq Maps** (لا تستخدم مفتاح Vela) واحفظه في GitHub Secrets؛ لم يُضف بعد.
- **تغيير الحزمة:** `applicationId = com.iraqmaps.navigation` (يمكن تجاوزه بـ `-PappId=`). `namespace` الداخلي ما زال `app.vela` عمداً لتفادي إعادة كتابة واسعة.
